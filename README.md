# EJS Instagram Project

A beginner-friendly Instagram-style web application built using Node.js, Express.js, and EJS.

## Features
- Dynamic Instagram-style user profiles
- Displays followers and following
- Displays posts, likes, and comments
- Supports multiple users (Cats and Dogs)

## Technologies Used
- Node.js
- Express.js
- EJS
- HTML
- CSS
- js

## Installation

1. Clone the repository:
   git clone https://github.com/mayankkhinchi03/ejs-instagram-project.git

2. Install dependencies:
   npm install

3. Start the server:
   node index.js

4. Open in browser:
   http://localhost:8080/ig/cats
